# Neon Forms 50 — MUTATION LAB

A separate experimental Serum 2 pack. This collection is intentionally more character-forward than the original Neon Forms 100.

The pack uses stronger wavetable warping, more extreme FM/RM/phase-style movement, broader modulation ranges, layered effects, more unusual oscillator intervals, and deliberately non-default combinations.

The original `Neon_Forms_100_Serum2.zip` is preserved separately.
