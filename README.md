# Neon Forms 100 — Serum 2

100 original Serum 2 preset patches generated for this repository.

Focus:
- polished, modern tone
- varied wavetable choices and oscillator relationships
- controlled modulation and stereo movement
- restrained distortion/reverb
- intentionally low background/noise character

The repository contains the full preset collection as a downloadable archive and a JSON manifest.

The SerumPreset container follows the documented Serum 2 XferJson + Zstandard + CBOR structure.
