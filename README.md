# Neon Forms 100 — Serum 2

A collection of 100 original Serum 2 patches.

The repository contains:
- 100 individual `.SerumPreset` files in `Presets/Neon Forms 100/`
- `Neon_Forms_100_Serum2.zip` for one-click download
- `manifest.json` with the full preset index
- `scripts/generate_presets.py` for deterministic regeneration

The generator is intentionally biased toward controlled FX, clean stereo movement, and a restrained noise floor rather than excessive ambience.

Generated target: Serum 2.1.4.
